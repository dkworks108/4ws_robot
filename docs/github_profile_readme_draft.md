## Featured Project

### `4ws_robot` — Four-Wheel Steering Autonomous Mobile Robot

- **Repository:** [https://github.com/dkworks108/4ws_robot](https://github.com/dkworks108/4ws_robot)
- **Status:** Active Development / Beta
- **Highlights:**
  - 8-DOF Four-Wheel Steering and Four-Wheel Drive (`4WS/4WD`) robot model simulated in Gazebo Fortress with `ros2_control`.
  - Five kinematic steering modes (`Ackermann`, `4WS Counter-Phase`, `Crab`, `Swerve`, `Rotation-In-Place`) paired with closed-form least-squares odometry.
  - SLAM Toolbox mapping, Nav2 navigation, frontier-based exploration, and a safety-arbitrated (`MANUAL`, `NAV2`, `EXPLORE`, `ESTOP`) desktop/mobile ground-control UI.
  - Ongoing external **Dubant** control/server beta integration testing.
